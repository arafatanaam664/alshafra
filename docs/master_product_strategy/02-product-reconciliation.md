# 02 — مطابقة الرؤية مع ما نُفّذ

| الموضوع | القرار القديم | الرؤية النهائية | الإجراء |
|---|---|---|---|
| الهوية | بوابة تقويم / «ثمانية أعمدة» | منصة أم متعددة الأقسام | واجهة عامة بلا لغة تخطيط |
| التقويم | «الموقع السابق» | قسم طبيعي | `/calendar` بدون سرد الهجرة |
| الأقسام | مصفوفات في الواجهة فقط | كتالوج + لوحة تحكم | `PLATFORM_SECTIONS` + Admin |
| التفعيل | بطاقات «قريبًا» | إخفاء غير الجاهز | `enabled && hasPublicPage` |
| الدول | هوية سعودية | عربي قابل للتوسع | بيانات لا صفحات رقيقة |
| CMS | Phase 5 محرر محتوى | إدارة أقسام لاحقًا | عقد جاهز، لا CMS كامل جديد |
| 127 URL | محفوظة | محفوظة | لا تغيير مسارات |
| المجتمع/OAuth/AI | مؤجلة | مؤجلة | الأعلام مطفأة |

الرؤية النهائية أعلى من أي ADR قديم يتعارض معها في لغة المنتج. الكود الصحيح يبقى.
