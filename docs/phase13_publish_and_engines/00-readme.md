# Phase 13 — نشر الموقع والمحركات

حلقة النشر: حفظ/نشر في اللوحة → لقطة `cms-snapshot.json` → صفحات Astro بعد البناء.

المحركات الجديدة جاهزة ومطفأة للزائر:

| محرك | العلم | الظهور العام |
|---|---|---|
| الفرص/وظائف/منح | `jobs_enabled` / `scholarships_enabled` / `opportunities_enabled` | فقط منشور + مصدر + غير منتهٍ |
| المجتمع | `community_enabled` + `questions_enabled` | noindex، الكتابة 404 إذا توقف |
| النشر الاجتماعي | `social_auto_publish_enabled` | طابور + عامل، بلا OAuth |
| الأتمتة/الإشعارات | القواعد متوقفة + `notifications_enabled` | لا تشغيل بلا تفعيل |
| الإعلانات | `ads_enabled` + معرّف خانة | لا عنصر إن توقف العلم |
| التحليلات | حدث حقيقي فقط | صفر أفضل من رقم كاذب |
