# Phase 17 — Brand unification

Visible chrome (header, footer, error pages, legal pages, resolved titles) uses **Alshafra**.

JSON-LD `alternateName` may still list «تقويم السعودية» for search engines. That string is not shown in the page body.

`apps/web-legacy` keeps the old Vite brand because it is rollback only.

Content that legitimately discusses Saudi calendars, salaries, or holidays is not rewritten just because it contains «السعودية».
