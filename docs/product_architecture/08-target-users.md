# 08 — Target Users

## Primary

### 1. Practical seeker (Saudi / Gulf resident)

Wants a date, a payday, a conversion, a holiday, a school break. Arrives from search. Low patience. Needs the answer **above the fold**, then explanation.

**Jobs:** `/today`, `/date-converter`, `/salaries`, `/countdown/*`, `/holidays`, `/school-calendar`.

### 2. Tool user

Wants to do something: convert, calculate age, check gold, decorate a name. Will share a result. Needs speed and copy-to-clipboard.

### 3. Guide reader

Wants to understand a process (Citizen Account eligibility, how conversion works, how to avoid gold-quote mistakes). Needs sources and updated dates.

## Secondary (activate later)

### 4. Question asker

Tried the guide, still stuck. Community. Must not flood the index with duplicate questions.

### 5. Expert answerer / trusted user

Builds reputation. Later.

### 6. Opportunity seeker

Jobs, scholarships, comparisons. Later flags: `jobs_enabled`, `scholarships_enabled`.

### 7. Editor / SEO manager / moderator / social manager

Internal users. Need CMS, flags, queues, audit logs. These are **day-one architecture**, even if community is off.

## Not a target

- Users expecting a government e-service replacement.
- Users expecting live licensed FX/gold execution prices.
- International SEO expansion before Arabic quality is stable.

## Implications

- RTL, Arabic typography, and Riyadh-timezone truth are default.
- YMYL tone: calm, sourced, no clickbait countdowns that lie.
- Homepage must serve seekers **and** introduce the wider platform without hiding the calendar cluster.
