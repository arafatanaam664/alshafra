# 35 — Admin Dashboard

Admin is a separate app shell (`/admin`), noindex, auth required.

## Nav

Dashboard, Content, Categories, Tags, Media, Tools, Community, Users, Moderation, SEO (redirects, robots, sitemap), Social, Automation, Analytics, Notifications, Settings, Feature Flags, System Health, Audit Logs.

## Dashboard widgets

- Publish queue
- Failed jobs
- Moderation count
- Indexable URL count vs sitemap
- Price snapshot age
- Flag states

## Constraints

- RTL Arabic UI
- Every destructive action confirmed
- Analyst cannot publish
- Super Admin only: role grants, secret view
