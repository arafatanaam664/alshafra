# 12 — Scripts (root)

| Script | Meaning |
|---|---|
| `npm run dev` | Vite public app |
| `npm run dev:admin` | Admin shell |
| `npm run build` | Vite + prerender **127 pages** |
| `npm run typecheck` | web + admin |
| `npm run lint` | web eslint |
| `npm run test` | urls + boundaries |
| `npm run check` | typecheck, lint, test, build |
| `npm run boundaries` | import rules |

Build scripts that generate HTML live in `apps/web/scripts/` (not domain logic).
