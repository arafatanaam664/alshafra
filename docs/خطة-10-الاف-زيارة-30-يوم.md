## 2️⃣ بنية الموقع العالمية (الأساس التقني)

```
https://alshafra.com/name-decoration          ← العربية (الجذر، لا تغيير)
https://alshafra.com/en/fancy-text-generator  ← الإنجليزية
https://alshafra.com/tr/sekilli-yazi          ← التركية
https://alshafra.com/fa/matn-fantazi          ← الفارسية
https://alshafra.com/fr/texte-style           ← الفرنسية
```
- **hreflang** لكل صفحة لكل اللغات + `x-default`
- **sitemap-index.xml** يضم sitemap لكل لغة
- **مبدّل لغة** في الهيدر + **RTL/LTR** تلقائي (عربي/فارسي RTL، الباقي LTR)
- **ملفات i18n** لكل لغة: عناوين، أوصاف، واجهات، FAQ — منطق الأدوات نفسه لا يُترجم
- **canonical مستقل** لكل نسخة لغوية
- ⚠️ **إيران:** تقويمها **شمسي (جلالي)** وليس هجرياً قمرياً — النسخة الفارسية تحتاج محول التاريخ الشمسي، وليس نسخ العربية

## 7️⃣ الأرقام الواقعية (مع تغطية كل المجموعات)

**10,000 زيارة/شهر = 333 زيارة/يوم.** التغطية الكاملة ترفع السقف لكنها **لا تغيّر فيزياء الفهرسة**: جوجل يحتاج وقتاً للزحف والثقة.

| السيناريو | الزيارات خلال 30 يوماً |
|---|---|
| تنفيذ ممتاز (الخطة أعلاه) | **3,000 – 10,000** |
| اختراق كامل (فهرسة سريعة + تركي/فارسي يتصدر + موسم سعودي + إنجليزي long-tail) | 10,000 – 15,000 |
| الشهر 2 (استمرار) | 15,000 – 40,000 |
| الشهر 3 (تغطية كاملة + سلطة) | 40,000 – 100,000 |

**منطق الأرقام:** 5 لغات × أدوات × أسعار × مواسم = عشرات الفرص المستقلة. التركية والفارسية تتصدر خلال 2–4 أسابيع، العربية في ذروتها الموسمية الآن، والإنجليزية تلتقط long-tail بحجم سوق هائل.

> **الصدق المطلوب:** وعد الذكاء الاصطناعي السابق («10K–100K يومياً») غير واقعي. الأرقام أعلاه مبنية على منطق الفهرسة والمنافسة.

## 8️⃣ قواعد الجودة والأمان (إلزامية — تحمي أدسنس والترتيب)

1. **لا صفحات رقيقة:** أداة = أداة تعمل + 200–300 كلمة + FAQ | مقال = 800+ كلمة | صفحة سعر = جدول محدث + تحذير «للاسترشاد»
2. **لا ترجمة آلية خام** — واجهات الأدوات قصيرة، تُترجم يدوياً بجودة عالية
3. **لا «فك كلمة سر»** — محتوى ضار غير قانوني
4. **لا صفحات تشبه التصيّد** («تسجيل دخول انستا») — أدلة إرشادية فقط
5. **لا صور مسروقة** (خلفيات/صور حب/حزينة) — محتوى مولّد أو مرخّص فقط، وشهر 3
6. **الأسعار تُحدَّث يومياً** أو لا تُنشر أصلاً
7. **لا باك لينك مشترى / Web 2.0 سبام** — عقوبة جوجل
8. **المحتوى المحلي يبقى محلياً:** رواتب السعودية = عربي فقط؛ لا تُترجم لمحتوى عالمي بلا قيمة
