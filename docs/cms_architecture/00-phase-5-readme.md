# 00 — Phase 5 README

Admin CMS foundation for Alshafra. Public site stays Astro SSG. Admin is `apps/admin` (Vite + React, `noindex`).

```
Admin UI → /api/v1/admin → @alshafra/cms services → PostgreSQL
```

No service-role in the browser. No community/social/AI in this phase.

```
npm run dev:admin
npm run test:cms
```
